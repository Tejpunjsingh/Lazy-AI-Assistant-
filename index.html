What “offline” means here

Honest by design

Works locally: tasks, notes, the focus timer, saved preferences, and the basic interface use files served from your own computer and browser storage. Once the project files are on your computer, core features need no internet.

AI needs a local model: the assistant sends prompts to the local server at 127.0.0.1, which calls Ollama on your machine. Downloading Ollama and a model requires internet the first time. Afterward, inference can run offline if the model is installed.

Open-source note: LazyDesk's code is provided under the MIT License. Ollama is an open-source local model runner; model licenses vary, so check the license of the specific model you download. No external analytics or cloud AI API is built in.
